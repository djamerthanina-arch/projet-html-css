# Projet de création web – HTML & CSS

## Présentation

Ce projet a été réalisé dans le cadre de ma formation en informatique. Il consiste à créer un site web composé de plusieurs pages autour de la boulangerie et de recettes.

L'objectif était de mettre en pratique mes connaissances en HTML et CSS, de travailler sur la structure des pages et leur présentation.

## Technologies utilisées

- HTML5
- CSS3

## Pages du site

- `index.html` : page d'accueil
- `propo.html` : présentation
- `recettes.html` : recettes
- `recettes_couscous.html` : recette de couscous
- `recettes_gateau.html` : recette de gâteau

## Compétences travaillées

- Structure d'une page HTML
- Mise en forme avec CSS
- Organisation de plusieurs pages web
- Intégration d'images
- Navigation entre les pages

## Objectif

Mettre en pratique mes connaissances en développement web et progresser dans la création de sites internet.
